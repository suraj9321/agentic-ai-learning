# Example questions (style guide for the quiz-me skill)

Loaded only when the skill needs it: this is **progressive disclosure** (Phase 8 lesson 03).

- Explain it: "The model returned `stop_reason: tool_use`. What exactly does your code do next, message by message?"
- What happens if: "You forget to send the `tool_result` for one of two parallel tool calls. What does the API do?"
- Find the bug: "This loop never ends. Why?" (show 6 lines with `messages.append` missing)
- Trade-off: "Your RAG bot answers from the wrong policy version. Name three causes and how you'd detect each."
- System design: "Design an agent that books meetings. Where do you put human approval, and why there?"
